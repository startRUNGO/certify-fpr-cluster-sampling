# P5 迭代 3 预注册：S2d（图像级偏移的层级混合模型）

写于 2026-10-22，早于任何 S2d 数字（含诊断数字）。设计：P4 会话；执行口径补全：P5 会话（标“执行口径”处）。母文件：PREREG_ITER1_20261022.md（143a07d4…a4a4d）、PREREG_ITER1_ADDENDUM_S3S2b_20261022.md（266da7fb…8e3a）、PREREG_ITER2_S2c_20261022.md（0dda7bb0…0db9）。CPU only，只读已保存的逐样本 logit（runs/iter1_20261021/infer），分数 s = logit1 − logit0；不训练、不用 GPU。

## 0. 诊断先行（使用标签，仅作诊断）
A2 seed 41，三个站点（NIH 锁定折、BBBC-ALL、MP-IDB），对真阴性细胞的得分：报告“每图减去该图真阴性中位数”前后的 IQR。**执行口径**：只纳入含 ≥5 个真阴性的图像（NIH 为视野图），IQR 在纳入图像的全部真阴性上计算；缩窄比例 = 1 − IQR_after/IQR_before。**停止规则**：BBBC-ALL 与 MP-IDB 两个外部站点中，只要任一站点缩窄 < 30%，报告结果并停止，不做 S2d 拟合。NIH 只作对照，不参与停止判定。

## 1. 模型
s_ij = δ_i + e_ij；e_ij 的密度为 (1−π)·f0((e−a0)/b0)/b0 + π·f1((e−a1)/b1)/b1，i 为图像（NIH 视野图 / BBBC-ALL 原图 / MP-IDB 图像），j 为细胞。

## 2. 源端形状（每个检查点；NIH 验证折；使用该折的标签）
每个视野图按其未感染细胞得分的中位数居中；居中后的未感染得分构成 F0 样本，再按自身中位数与 IQR 标准化（z0），KDE 同 S2c（Silverman 带宽，2048 点网格，网格外 1e−12）。F1：寄生细胞得分减去其所在视野图的未感染中位数（**执行口径**：无未感染细胞的视野图不能居中，其寄生细胞不纳入 F1），再按自身中位数与 IQR 标准化。Q0(·) 为 z0 的经验分位数。

## 3. 目标站点拟合（无标签；EM over images）
- E 步：r_ij = 细胞 ij 为阴性的后验概率 = (1−π)f0((e−a0)/b0)/b0 / 混合密度，e = s_ij − δ_i。
- M 步（偏移）：δ_i = (Σ_j r_ij)/(Σ_j r_ij + n0) × 加权中位数_j(s_ij − a0；权重 r_ij)，n0 = 10 事先固定（对阴性相信少的图像向 0 收缩）。
- M 步（站点参数）：(π, a0, b0, a1, b1) 由加权最大似然得到，e_ij = s_ij − δ_i。**执行口径**：最大化期望完全数据对数似然 Σ r_ij log[(1−π)f0(·)/b0] + (1−r_ij) log[π f1(·)/b1]；π = mean(1 − r_ij)（裁剪到 [0, 0.95]）；(a0, ln b0, d = a1 − a0, ln b1) 用 L-BFGS-B 数值优化，约束 d ≥ 0、ln b ∈ [−10, 10]、a ∈ [−200, 200]，从当前值出发，最多 100 次迭代。
- 初始化：δ_i = 图像中位数 − 站点中位数（无标签）；e = s − δ，以 S2c 的起点值（a0、b0 = e 较低一半的中位数与 IQR；a1、b1 = e 最高 10% 的中位数与 IQR；π = 0.2）开始，先做 E 步（r 初始为全 1 的含义是起点处先用该起点值算 r）。
- 5 次重启（第 1 次如上；第 2–5 次 π 起点 0.05、0.1、0.3、0.5，a0、b0、a1、b1 起点各乘 exp(N(0,0.2²))，种子 20261022），每次最多 50 轮 EM，观测对数似然的相对变化 < 1e−6 时停止；保留最终观测对数似然最大者。无退化保护。

## 4. 阈值与评估
每细胞 τ_i = δ_i + a0 + b0·Q0(0.95)（目标 5% FPR）。判为阳性：s_ij ≥ τ_i。
对比：S2（组内 MAD，runs/iter1_20261021/s2）、S2c (i)（runs/iter1_20261021/s2c）、源 Youden 阈值、oracle（标注，只作诊断）。集：NIH 锁定折、BBBC-ALL、MP-IDB（原 BBBC041 无图像 ID，不可做）。检查点：A2 与 A0-ctrl 的 s41–s45。报告：平衡准确率、灵敏度、实际 FPR、π̂ 对真实站点阳性率、按图真实阳性率分档（<5%、5–20%、>20%）的结果、δ_i 估计的平均绝对误差、拟合后居中的混合图（A2 seed 41）。**δ_i MAE 口径**：估计的图像阴性位置 = δ_i + a0；对照真实图像阴性位置 = 该图真阴性得分的中位数（仅含 ≥5 个真阴性的图像）；MAE 取绝对分数差的平均。
**判据同母文件 §1**：S2d 在 BBBC-ALL 与 MP-IDB 上平衡准确率均不低于源阈值，至少一个提高 ≥ 0.05，NIH 锁定折下降 ≤ 0.01（5 种子均值）。不改判据，不因结果调整 n0、重启、带宽、网格。
