## S5a 可交换律
- 在 D1（n 个阴性分布在 n 张不同图像，每图 1 个）下，n 个阴性的第 k 个次序统计量的真 FPR 服从 Beta(n−k+1, k)；覆盖率 P(FPR ≤ ε) = I_ε(n−k+1, k)（正则化不完全 beta 函数，scipy.special.betainc）。
- 规则 R1：最小的 k ∈ {1,…,n} 使 I_ε(n−k+1, k) ≥ 1−δ；阈值 τ = n 个得分的第 k 小值；若不存在，报告“n too small”，**执行口径**：此时仍取最大值（k = n）作为回退阈值并标记，其覆盖率照常报告。
- 解析：对两个设定给出 n_min（k = n 可行的最小 n，即 1−(1−ε)^n ≥ 1−δ）及 n ∈ {10, 20, 30, 50, 100} 的 k。
- 经验检验：BBBC-ALL、MP-IDB、NIH 锁定折，n ∈ {10, 20, 30, 50, 100}，每个 (检查点, 种子, 站点, n) 200 次抽样，5 种子合并为 1000 次；实际 FPR = 其余全部真阴性（去掉被抽中的 n 个）上得分 ≥ τ 的比例；覆盖率 = 1000 次中实际 FPR ≤ ε 的比例；n 超过该站点含真阴性的图像数时记 n/a。
- 报告灵敏度及其与两个参照的差：FPR=0.05 参照与 FPR=ε 参照（站点全部真阴性的 1−0.05、1−ε 分位数阈值处的灵敏度）。

## S5b 聚类抽样
设计：D1；D2（n 个全部来自同一张含 ≥n 个真阴性的图像）；D3：m 张图像 × 每张 r 个阴性，(m, r) ∈ {(5,4), (10,2), (5,10), (10,5), (20,5)}（从含 ≥r 个真阴性的图像中无放回抽 m 张，每张无放回抽 r 个）。D1、D2 取 n ∈ {20, 50}。
- R1-naive：对 n = m·r 个得分直接用 R1。
- R2（聚类校正）：对 n 个得分按图像做单因素 ANOVA（均衡设计）：MSB = r·Σ_i(均值_i − 总均值)²/(m−1)，MSW = ΣΣ(x − 均值_i)²/(m(r−1))，ICC = (MSB − MSW)/(MSB + (r−1)·MSW)，截断到 [0,1]；n_eff = n/(1+(r−1)·ICC)；对（实数）n_eff 求最小整数 k' ∈ {1,…,⌊n_eff⌋} 使 I_ε(n_eff−k'+1, k') ≥ 1−δ（不存在则 k' = ⌊n_eff⌋ 并标记 too small）；分位水平 p = k'/n_eff，取 n 个得分的第 min(n, ⌈p·n⌉) 小值为阈值。m = 1（D2）或 r = 1（D1）时 ICC 不可估，n_eff = n（R2 = R1）。
- R3（图像级）：每张图像取其 r 个阴性的最大值，得 m 个统计量；在图像层面应用 R1（Beta 律，n 取 m），目标 ε_img = 1 − (1−ε)^r。推导（P4 会话要求写明）：若同一图像内阴性可交换且各图像同分布，则图像内 r 个阴性的最大值超过 τ 的概率为 1 − (1−p)^r（p 为单细胞超过率）；令其等于 ε_img 即得 p ≤ ε 对应的 ε_img = 1 − (1−ε)^r；该推导需要各图像同质，图像间异质时不保证，故经验检验覆盖率。**次要变体 R3c（保守）**：ε_img = ε，理由：1 − (1−p_i)^r ≥ p_i，故图像级超过率 ≤ ε 蕴含平均单细胞 FPR ≤ ε（无需同质）；R3c 只作报告，不计入判据 (2)。
- 报告：每个设计、每个站点、R1-naive/R2/R3/R3c 的覆盖率与灵敏度（及与两个参照的差）。
- 随机数（所有规则共用同一抽样，配对）：numpy default_rng([20261022, 5, 检查点序号, 种子, 设计编号, n 或 100·m + r, 站点序号])。
