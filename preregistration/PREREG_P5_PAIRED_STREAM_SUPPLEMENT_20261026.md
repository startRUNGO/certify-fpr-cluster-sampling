## 1. 要解决的缺陷

两份预注册各给了一个新的随机数站点序号（33、32），所以重算时抽到的视野组合与旧版 Lacuna-B 不一样（旧版 rev1 用的是键 8、序号 2）。结果是，新旧之间的每一个差值里，都混着去重或取景的作用，加上随机流不同带来的抽样噪声。

证据：
- 只依赖阴性的方法（B1、B1u、R1），去重或重建不可能改变它们，但覆盖率差最大约 0.04；
- 同一个量在两个脚本中的差值方向相反。

所以：
- lb_dedup 的覆盖率差（|Δ| 最大 0.038–0.058）无法归因；
- lh 在 ε = 0.05 下灵敏度 +0.060 中，取景的作用占多少，也无法确定。

## 2. 改动（只改随机流）

- lb_dedup 和 lh 中所有用到随机数的派生脚本，把种子表达式**逐字恢复**成"产出旧版对照值的那个原脚本"对 Lacuna-B 用的表达式，包括键、序号和参与种子的 arm 下标。
  - 例如 rev1：`[20261022, 8, ai, sd, m, 2]`，其中 2 是 lacuna_B 在原 SITES 列表里的下标。
  - 涉及的派生脚本：rev1、rev7、s5、s6、s7、s10、s11、fieldstats。
  - fork 要为每个脚本列一张对照表交审，每行写明：派生脚本 → 产出旧对照值的结果文件（例如 runs/rev1/rev1_results.json）→ 生成它的原脚本（路径和 sha）→ 原种子表达式在 Lacuna-B 下的取值 → 新种子表达式。ARMS 的顺序也要与原脚本逐项核对，因为 arm 下标会进入种子。
- 站点名照旧（lb_dedup、lh）。数据加载、统计定义、判据、候选集一律不改。
- 只用 CPU，不推理，直接复用已有的 logits：
  - lb_dedup 用旧 E7 的推理产物；
  - lh 用 `runs/lacuna_hc_20261025T221212Z/infer/` 中的 logits。

  lh_infer 不重跑。
- 旧版 s6bc 没有 Lacuna-B 的条目，所以 s6 没有可以恢复的原随机流，保持原样，不参与配对比较。
- 输出写到新的时间戳目录，不覆盖任何已有结果。

## 4. 读法

**结论只用配对之后的差值来写。**

**lb_dedup：**
- 覆盖率 |Δ| ≤ 0.01 时，写"去重对 FPR 认证无实质影响"；否则如实写出差值。
- 这条判据沿用原预注册 §4，不改。
- 只依赖阴性的量的差值按上面的校验恒为 0；有实质意义的是 S3（它用标注阳性在候选之间选择）和各种灵敏度。

**lh：**
- Q2 按母文件原判据重新判读：S3 的实现灵敏度、ΔSens_ε、ΔSens^own，|新 − 旧| ≤ 0.05，称"对取景稳健"；> 0.05，称"旧版含取景混杂"。ε = 0.10 和 ε = 0.05 分开报告。
- Q1、Q3、Q5、Q6、C2、B1u-c0 各项，按配对值照原读法重写。

**配对的范围与阳性相关差值的区间（10-26，按实验管理审阅补充）：**
- **阴性一侧逐项相同。**同一个种子只对数组没有变的量给出逐项相同的抽样。阴性一侧正是这种情况，所以第 3 节的校验要求差值为 0。
- **阳性一侧只是"公共随机数"意义上的配对。**去重或重建之后，阳性的数组变了。以 rev1 为例，每次抽到的视野相同，阴性子样本也相同，但抽到的视野里阳性的个数和分数变了；凡是对阳性做重抽的脚本，同一种子下也不再逐项对应。所以抽样噪声大幅减小，但不为零。
- **阳性相关的差值要给区间。**所有与阳性相关的差值（S3 的覆盖率、选择频率，各方法的灵敏度和 ΔSens），除点估计外，还要给出**配对区间**：
  - 每次抽样（1,000 次）在新旧两边各算一次，取每次的差值，对这 1,000 个配对差值做 bootstrap，重抽 10,000 次，报 95% 区间；
  - 两边用同一组抽样下标。
- **为此允许的唯一额外改动：**配对脚本可以把 S3 和比较链（R1-all、R1-2、B1、B1u_c0/c1s/c2s）每次抽样的 cert、fpr、sens、所选候选另存为 npz。这只增加输出，不改变任何计算。
- **判读用区间：**结论按点估计和区间一起写。原预注册里的阈值（|Δ| ≤ 0.01、≤ 0.05）用点估计来判；区间跨过阈值的，要写明"在抽样误差范围内不能确定"。

**分解（事先写定，只作描述）：**三次配对运行用的是同一个随机流，所以旧版 → lh 的差值可以拆成两段：
- 旧版 → lb_dedup：去重的作用；
- lb_dedup → lh：重建的作用。

逐项报告两段的贡献。需要说明的是，重建同时改了两件事：一是取景，二是阳性群体，只保留 Hough 检测到的阳性，召回约 0.715。这两者的作用无法分开，"lb_dedup → lh"这一段要如实写成"重建（取景 + 阳性群体）"，不写成"取景"。Q2 的判据仍按母文件，用旧版对 lh 的差值来判。

**两项都适用：**
- 序号 33 和 32 那两次的结果保留，在补充材料中作为"随机流敏感性"报告。其中只依赖阴性的量，两次之间的差值，可以直接当作抽样噪声的量级。
- 稿件里的主数字改用**配对重算的值**。
