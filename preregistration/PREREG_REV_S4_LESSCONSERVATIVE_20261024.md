## 0. 为什么改：已测到的不足

冻结规则 S3（PROTOCOL_FREEZE_20261022.md，sha256 f2565f30…）认证得过严。下表为 A2，m=22，五个站点的现有结果（rev1_results.json、r8_rev1_results.json）：

| 站点 | ε | 覆盖率（要求 ≥ 0.90） | 实现 FPR 均值 | ΔSens^own（相对 S3 自己中心化分数上的 oracle_ε） |
|---|---|---|---|---|
| BBBC-ALL | 0.10 | 0.993 | 0.056 | −0.111 |
| MP-IDB | 0.10 | 0.987 | 0.048 | −0.040 |
| Lacuna-B | 0.10 | 0.945 | 0.062 | −0.073 |
| PlasmoCount | 0.10 | 0.998 | 0.071 | −0.007 |
| IML | 0.10 | 0.974 | 0.054 | −0.158 |
| BBBC-ALL / MP-IDB / Lacuna-B | 0.05 | 0.989 / 0.989 / 0.924 | 0.022 / 0.021 / 0.031 | −0.239 / −0.106 / −0.186 |

覆盖率普遍远高于 1−δ = 0.90，实现 FPR 只用了 ε 的一半左右。ΔSens^own 主要就是这份多余的保守。

**解析分解**（不看数据，只代入 S3 的公式；m=22，等大小视野，视野内相关 ρ，真实 FPR 为 p 时 S3 的上界恰好等于 ε 的 p 值，记为"可认证 FPR"）：

| 场景 | S3 | 把 ICC 上限换成真值（CP 仍在 δ/3） | 再把 CP 放到 δ |
|---|---|---|---|
| ε=0.10, N=2400, ρ=0.05 | 0.061 | 0.071 | 0.079 |
| ε=0.10, N=2400, ρ=0.15 | 0.038 | 0.052 | 0.065 |
| ε=0.05, N=2400, ρ=0.05 | 0.021 | 0.029 | 0.035 |
| ε=0.05, N=2400, ρ=0.15 | 0.005 | 0.016 | 0.024 |

两个来源：

- **(i) ICC 的置信上限：** 设计效应用的是 ICC 的置信上限（δ/3 水平），之后又在同一 δ/3 上做 Clopper–Pearson，相当于把不确定性计了两次。这是最大的一项，ρ 越大越严重。
- **(ii) 联合界：** 三个候选各用 δ/3，这部分是选择所必需的，本轮保留。

## 1. 改动（两个变体，其余与 S3 完全相同）

两者都只替换第 3 步里的"ICC_U → n_eff"，网格、固定序列（第一次失败即停）、三个中心化候选、δ/3 联合界、按已标阳性灵敏度选择、cannot-certify 规则全部不变。

- **S4a（ICC 点估计）：**
  - 用 S3 已有的方差分析 F 统计量算 ICC 点估计：θ̂ = (F − 1)/n0，ICC_hat = θ̂/(1+θ̂)，截断到 [0, 1]；MSW = 0 时按 S3 的同一约定。
  - 然后 n_eff = N/(1 + (n̄_w − 1)·ICC_hat)，x_eff = ΣX·n_eff/N，UB = Beta⁻¹(1 − δ/3; x_eff+1, n_eff − x_eff)。
- **S4b（视野级稳健方差的设计效应）：**
  - p̂ = ΣX_i/N。
  - 比率估计的线性化方差：v̂ = m/(m−1) · Σ_i (X_i − p̂ n_i)² / N²。
  - 设计效应：DEFF = v̂ / (p̂(1−p̂)/N)，下限截断为 1；p̂ ∈ {0, 1} 时取 DEFF = 1。
  - n_eff = N/DEFF，x_eff = p̂·n_eff，UB 同上（Clopper–Pearson 在 δ/3）。

两者都是渐近近似，与 S3 一样不是有限样本保证；覆盖率靠经验评估。

## 3. 判据（A2，m=22，两个 ε 分别判定）

- **安全条件：** 三个开发站点上覆盖率都 ≥ 0.90。另在 m=10 上覆盖率都 ≥ 0.85，防止小样本下失控。
- **改进条件：** 与 S3 的配对灵敏度差，在三个站点的平均值 ≥ +0.02，且没有站点低于 −0.01。
- **选择：**
  - 两个变体都满足时，选平均灵敏度增益大的；
  - 只有一个满足就选它；
  - 都不满足，就保留 S3，并如实报告哪一条没过、差多少。
- A0-ctrl 只报告，不参与判定。
- **再优化：** 如果安全条件失败的原因是 v̂ 在小计数时低估（p̂ 很小、只有个别视野有超阈细胞），下一轮的改动方向预先写明：给 DEFF 加一个由 S3 ICC 点估计给出的下限，即 DEFF ≥ 1 + (n̄_w − 1)·ICC_hat。本轮不实施。
