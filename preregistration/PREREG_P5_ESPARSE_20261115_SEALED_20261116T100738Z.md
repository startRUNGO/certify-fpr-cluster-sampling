## A. 操作性定义（补充，原文未写死的部分）

A1. **规则 R1** = mh_s5.py（sha256 f9d331d5…）里的 R1 函数逐字复制：最小 k 使 Beta(n−k+1, k) 在 ε 处的分布函数 ≥ 1−δ；阈值取已标注阴性的第 k 小值；无 k 满足时（cannot certify）阈值取样本最大值（与 S3 的回退阈值 grid[0] 同口径）；零个阴性则 τ=+∞（FPR 0，计入 cannot certify）。**不**用 ebatch_lib.CP 的"空抽样计为覆盖"口径。脚本启动先核 R1 的解析锚：n_min=22（ε=0.10）、45（ε=0.05）；ε=0.10 时 n=30/50/100 的 k=30/49/95（均取自已存 s5 解析表）。
A2. **D1-n**（实验管理裁定：按卡）：在全部含细胞的视野中不放回抽 n 个，每视野在该视野**全部细胞**中均匀抽 1 个并标注（按卡）；抽到感染细胞则该视野不贡献阴性，R1 用实际得到的阴性数。标注成本 = n 个细胞。已有 5.8 节的 D1 与此不同：s5 只在阴性细胞里抽（"50 图×1 阴性"），其 FPR 评价排除了已抽的细胞（mh_s5.py:78，fpr_at(t, drawn)）；本脚本评价用全站总体（库约定）。所以 0.978/0.978/0.969 不会原样重现。**精确性的口径**：D1 的 R1 对"先随机抽视野、再在视野内随机抽 1 个细胞"所诱导的分布（视野加权）是精确的，而评价目标是全站细胞加权的 FPR；各视野阴性数不等时二者不同。本草稿不做任何修正，也不另算视野加权 FPR，差别体现在实测覆盖里，如实报告。
A3. **D5-n**（卡里的 Dk-n，k=5）：在细胞数 ≥5 的视野中不放回抽 n 个，每视野不放回随机抽 5 个细胞（保留随机顺序）。规则 R1：5n 个细胞中的阴性合并后用 R1（不精确，作对照）；规则 R1-1：每视野只取随机顺序中第一个阴性细胞，用 R1。两者标注成本都是 5n 个细胞。⟨R1-1 的成本与 D5 相同却只用 1/5 的细胞，按成本模型必被同 n 的 D1 压过；按卡保留，不删。⟩
A4. **n 网格**（裁定：D5 沿用 D1 网格）：D1、D5 都取 {22, 50, 100, 200, 400, 全部可用视野}，另加"等细胞点"（见 A5）；站内可用视野数不足的格子记为 INFEASIBLE，不外推。⟨卡只给了 D1 的 n 网格，D5 沿用同一网格。⟩
A5. **等细胞预算点**：F-m 标注的是视野内**全部细胞**（阴性和阳性），预算按全部细胞计：E_cells(m) = m × 含阴性视野的每视野平均细胞数（F 的视野正是从含阴性视野中抽，故用含阴性视野的均值；由站点计数算出，抽样前确定，与任何结果无关）。D1 等细胞点 n = floor(E_cells(22))；D5 等细胞点 n = floor(E_cells(22)/5)，取下整数使该臂在 r=0 时按构造可负担。可达性由脚本按站点视野数判定并写入输出；D1 的等细胞点三站可能都不可达（裁定接受），此时报告 D5 等细胞点（可达的站）与 D1 至全部可用视野。⟨与卡不同：卡按阴性计；已更正我先前草稿对 MP-IDB 428 的说明，428 是旧版 MP-IDB 的键（见第 B 节）。⟩
A6. **F-m**：m∈{22, 40}，规则 S3 与 SPLIT6，用冻结库 e2prime_mgrid.rows_for_m（L.M=m，REV-1 抽样流，SPLIT6 的 m_s=max(2,round(6m/22))）**重算**，并与已存 ebatch_e2p.json（sha256 2732653c61e1…）中同格覆盖率逐项核到 1e-12，不符则退出不写输出。重算的原因：已存聚合只有 ΔSens 和覆盖，没有绝对灵敏度与标注细胞数，而成本比较需要这两项。每次抽样的标注细胞数 = 所选视野内全部细胞数。**实现**：ebatch_lib 取 CP 重跑包内的版本（runs/ebatch_cp_rerun_20261110T003703Z/pkg/results_src/e_batch/ebatch_lib.py，sha256 41e5a9af50cb5ef3188ed18b43534ff1689276f3edddc7546d2e5361e25be311），与钉住的 ebatch_e2p.json 同源；它与 results_src/e_batch/ 里的版本（sha256 前 8 位 359b6bce）只差 CP 阈值的写法，本脚本不用 CP 规则，输出的 modules_sha256 记录实际使用的版本。
A7. **统一指标**（裁定接受）：覆盖、cannot certify、平均实际 FPR 在各臂同口径（全站总体上的 FPR，库约定）。灵敏度比较用**绝对灵敏度**（在全站阳性上）。ΔSens 对 D 臂是相对原始分数（c0）oracle，对 F 臂已存的 ds_own 是相对所选候选自己的 oracle，两者不同，因此只在 D 臂内部报 ΔSens(c0)，跨设计只比绝对灵敏度。⟨卡写"相对同一 oracle"；S3 选的候选是平移后的分数，其 oracle 与 c0 不同。⟩ **cannot-certify 的抽样**按回退阈值（样本最大值）计入灵敏度，两种设计相同；另列 sens_cert0（cannot certify 的抽样灵敏度记 0）作敏感性读数，不进判读规则。
A8. **抽样流**：D 臂 rng = default_rng([20261115, 7, 站序号, 种子, 设计码(D1=1,D5=5), n 码])，5 个种子 41–45 × 每种子 200 次 = 1000 次，一次抽样同时用于 ε=0.10 与 0.05；与表 5 一致的是种子、次数、总体与评价口径。D 臂的抽样本身与 F 臂不是同一条流（设计不同，无法共用）。F 臂用库的 REV-1 流（含 m）。
A9. **成本与 r\***：F-m 的成本 = m·r + E_cells(m)（总体期望标注细胞数，不用抽样的经验均值，使等细胞点在 r=0 时的可负担性不由抽样噪声决定）；臂 A 的成本 = n_A·(r + k_A)（D1 的 k=1，D5 的 k=5）。臂在 r 处"可负担"当且仅当其成本 ≤ F 的成本。r 的格点 R_GRID={0,1,5,20,60}，r\* 在 r=0,0.5,…,200 的细网格上取：最小的 r 使得对其后每个格点 r′，没有"有效且可负担"的臂的绝对灵敏度 > F 的灵敏度 + SENS_TIE。到 r=200 仍不成立时 r\* 记 None，算作 r\*>20。SENS_TIE = 0.01（裁定；1000 次抽样灵敏度标准误约 0.005 量级）。**对手集合**（⟨与卡不同⟩，裁定）：主读数的 r\* 只让有效规则参赛，即 D1|R1 与 D5|R1-1；D5|R1（5n 个细胞合并，同视野细胞相关，不精确）只作对照列，不进 r\*。另给只含 D1 的 r\*。理由：卡写明 D5|R1 已知覆盖偏低，让它参赛会因其无效而被有效性筛掉或靠不精确的阈值虚高灵敏度。输出同时给有效臂清单和 R_GRID 各点最优臂的预算使用比例。
A10. **有效性**：臂在某站的覆盖率的种子聚类 90% 区间下限（EB.seed_cluster_ci：5 个种子覆盖率重抽 10,000 次的 5–95 分位）≥ 1−δ−0.02=0.88。F 臂自身也要有效；F-22+S3 在某站无效时，该站不计入 A 或 B。
A11. **判读所用的格**：主判读用 ε=0.10、F-22、规则 S3（卡的"F-22 + S3"）；ε=0.05、F-40、SPLIT6 作为同表报告，不参与主判读。结论 A 与 B 按卡的字面（三站中至少两站），"其余情况"按卡处理。
A12. **范围与读取**：三个开发站，A2 冻结分数，种子 41–45。确认站、NIH 留出折、任何图像、任何分类器都不读。F 臂重算经冻结库读 NIH **验证折**（SPLIT6 的 Platt 步，e2prime_mgrid 同样如此；实验管理已裁定可读）。完整运行必须是 5 个种子 41–45，否则脚本拒绝运行（锚点与 verdict 依赖全部种子）；`--stats-only` 只输出站点计数（视野数、每视野细胞数与阴性数分位数、E_cells、等细胞点与可达性），不含任何分数或结果量。

## 3. 设计臂
- F-m：完整标注 m 个随机视野，规则 S3 和 SPLIT6，m ∈ {22, 40}（已有结果直接引用，同一抽样流重算核对）。
- D1-n：随机抽 n 个视野，每视野随机抽 1 个细胞并标注；抽到感染细胞则该视野不贡献阴性。规则 R1（精确）。n ∈ {22, 50, 100, 200, 400, 全部可用视野}，受各站视野数限制（MP-IDB 104）。
- Dk-n：每视野 k 个细胞，k ∈ {5}，规则 R1（不精确，作对照，已知覆盖偏低）和视野级有效规则 R1-1（每视野只用 1 个）。
- 等细胞预算点：D1-n 中 n = F-22 的平均阴性标注数（各站约 1369–2338），在视野数够的站报告；不够的站写"站内视野数不足，无法达到"。

## 4. 成本模型（标注时间未测，所以给出整条曲线）
成本 = c_f × 打开并定位的视野数 + c_c × 标注的细胞数。令 r = c_f / c_c。报告 r ∈ {0, 1, 5, 20, 60}，以及每站的"持平比 r*"：在该 r 以上，F-22 + S3 的灵敏度不低于同成本下最好的 D1-n。r = 0 即纯等细胞预算，r 很大即纯等视野预算。

## 5. 指标
覆盖率（实际站点 FPR ≤ ε 的抽样比例，附聚类置信区间）、ΔSens（相对同一 oracle）、平均实际 FPR、cannot certify 比例。全部按站、按 ε 报告。

## 6. 读数前写死的判读规则
- 有效性：某臂在某站覆盖率的置信下限 < 1 − δ − 0.02，则该臂在该站不参与灵敏度比较。
- 结论 A（保持现定位）：三站中至少两站 r* ≤ 20（即一个视野的定位成本不超过约 20 个细胞的标注成本时，完整标注视野已不吃亏）。
- 结论 B（调整叙述，不改题目）：三站中至少两站 r* > 20。此时正文把 D1 稀疏设计写成"可自由选细胞时的首选"，S3/SPLIT6 定位为"标注以完整视野为单位产生时"（常规计数流程本来就逐视野数完）的证书，并把这张对比表放进正文。
- 其余情况：按站如实报告，两种设计并列给出适用条件。
- 任何结果都报告，不因结果增删臂；r 的取值和 n 的网格读数后不改。
