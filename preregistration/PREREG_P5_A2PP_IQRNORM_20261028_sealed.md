## 2. 机制改动

### 2.1 前端 v2 `fgref_iqr_float_pr_od`（新函数；legacy 和 fgref v1 都保留不动）

对一张 uint8 RGB 图像（H×W×3）：
1. od、fg、ref 与 fgref v1 完全相同（A2′ 预注册 §2.1 第 1–3 步）：od 取 float32；fg 取 P2 前景，原样复制，断言 sha c5d09199；ref_c = np.median(od[fg, c])。
2. **离散度**：s_c = q75_c − q25_c，即 od[fg, c] 的 np.quantile，linear 插值，按通道分别计算。
3. **归一化**：z_c = (od_c − ref_c) / max(s_c, s_min)；od′_c = s0_c · z_c。
4. 其余与 legacy 相同：od′ 截到 ≥ 0（**保留单侧截断**，一次只改一处），restore = 256·10^(−od′) − 1，截到 [0, 255]，转 uint8。
5. **回退**：|fg| < 0.01·H·W 时（整数判定 100·|fg| < H·W），整张图退回 legacy，不做归一化，并计数。与 fgref v1 相同。

**常数（事先写定）**
- **s_min = 0.0048**：I = 180 处 2 个灰度级的 OD 间隔（log10(182/181) + log10(183/182) ≈ 0.0048）。依据是量化。实验管理已接受，之后不再调。触发次数要报告。
- **s0_c**：NIH 训练折 IQR_c 的中位数，按通道分别取，在第 4 节的 s0 样本上计算。**算出后写成本预注册的附录 S0，在任何新 M0 结果之前封存**，之后不再改。

**与 P6 端侧的关系**：P6 的 P4 已经在 G 内为每个通道建了 uint8 直方图。q25、q75 可以从同一直方图经 LUT 取得（OD 是强度的单调函数），0 B 额外内存、0 额外扫描。但主机端用 float 的 np.quantile（linear），端侧用直方图分位，**两者不逐位一致**；掩码也不同（fg 对 G）。稿件中写"概念统一"，不写"相同"。

## 4. 训练前的三步（依次进行，每一步都先审后跑）

### 4.1 合成测试（只报告，不设通过判据；本机，只用合成数组）

- 目的：在训练之前，先看清归一化对寄生虫对比度和量化噪声的影响。实验管理指出，现在没有依据事先定"多少压缩会伤害灵敏度"的阈值，所以只报告。
- 合成细胞：均匀亮度的圆盘，加上可控离散度的纹理。细胞内 OD 的 IQR 取 5 档，覆盖 NIH q10 到 BBBC q90：0.006、0.015、0.05、0.15、0.46。
- 寄生虫斑点：圆盘内的深色斑点，相对细胞的 OD 对比度取 4 档：ΔOD = 0.05、0.1、0.3、0.6。0.05 一档对应低对比度的环状体（实验管理审查 P-a 增加）。四档都是设计选择，都只报告。
- 报告：
  - 输出图像中斑点与细胞的对比度比（前端 v2 对比 fgref v1 和 legacy）；
  - 量化噪声的放大倍数 s0 / max(s, s_min)；
  - s_min 的触发情况；
  - 斑点使 s 增大了多少（对应风险 R1）。

### 4.2 s0 计算（VM 的 CPU）

- 样本：NIH 训练折，RNG 20261107，每类 150 张，排除以往全部 NIH 样本（20261028/29/30、20261103、20261104 的 M0 样本），断言交集为空。
- 输出：每通道 IQR 的中位数，即 s0_c，同时报告分位数。只计算这一组常数，不涉及任何模型和站点。
- **s0 依赖类别比例**（实验管理审查 P-b）：s0_c 是在阴性、阳性各 150 张、按 1:1 抽取的样本上取的中位数。由于寄生虫会撑大 IQR（风险 3），换一个类别比例，s0_c 就会改变。这个 1:1 的定义事先写定，不随任何结果改动。
- **只报告**：同一样本上阴性类和阳性类各自的 IQR_c 中位数（按通道）。这两个数只用来说明 s0 对类别比例的敏感程度，**不改变 s0 的定义**，也不用来选 s0。
- 写成附录 S0（本预注册的勘误或附录），交实验管理审、交用户确认后封存；**封存在新 M0 的任何结果之前**。

## 7. 风险

1. **噪声放大**：NIH 的平坦细胞按 s0/s 放大。s0 取 NIH 的中位数，所以 NIH 的典型细胞基本不放大；s_min 截住极平坦的细胞。由合成测试和新 M0 的 z 分布报告。
2. **寄生虫对比度被压缩**：高离散度站点（BBBC）的 IQR 是 NIH 的约 9–16 倍，寄生虫相对细胞的突出程度会被大幅压缩，可能伤害灵敏度。由合成测试报告。
3. **R1，IQR 与类别有关**：寄生虫会撑大 IQR，所以阳性细胞被压缩得更多，削弱的正好是阳性信号。由新 M0 中 NIH 的分类别 IQR 报告。
4. 重度感染时 fg 中寄生虫像素多，IQR 偏大，属于风险 3 的极端情况。
5. 前景掩码大面积出错时，ref 和 s 都会偏，这一点由新 M0 的掩码读数检查。
6. A2″ 不被采纳：先做根因分析，不调 s0、s_min，不加 epoch 后直接重训。
