## 1. 测到的不足（全部有数）

- **W-F（取景）**：同群体分解显示，A2 在 ε = 0.05 时的取景段为 +0.076 [0.073, 0.079]。C5b 用训练增强只把它降到 +0.046 / +0.050，还付出了 NIH 验证折 AUROC 下降 0.015 的代价（`P5_C5b_判读_20261027.md`，60deacda…）。结论：靠学习得到取景不变性，代价大、效果不足。
- **W-K（BBBC 的类条件偏移）**：
  - A2 在 BBBC-ALL 上的阴性分数相对 NIH 验证折，KS = 0.85，中位数高约 2.9 logit；AUROC 0.941（C3 判读）。
  - C3 已经说明，只改流行率的校正无效；C4 说明在打分端加头没有收益；C5b 也没有修复它（KS 0.67–0.82）。
- **W1（总目标）**：冻结 S3 在 ε = 0.10、m = 22 时的灵敏度，BBBC 0.819、MP-IDB 0.822、Lacuna-B 0.884。

## 2. 机制改动（三个配置，都不训练，都在冻结的 A2 检查点 s41–s45 上）

### C1a：推理端门控（针对 W-F）

把每个外部裁剪在推理前变成 NIH 的格式：单个细胞、门外为黑、裁剪框贴合细胞。

1. **门控**：用 P6 B0 流式门控，`Paper6_PathoTrunk/code/p6_streamgate_ref.py`（sha d2104e52…），即 M8 预注册 §2 的 P0–P3，在**原始分辨率**上运行。得到门控像素集合 G 和回退标志。
   - 该文件的 `run()` 同时计算 m2_cov 的头。fork 要把其中门控部分抽成 `gate(img)`，逐行不改。
   - 抽出的函数要先过一致性检查：在 B0 对拍用过的 65 张图上，`gate()` 的掩码与 `run()` 返回的 `mask` 逐像素相同，差为 0。不通过就停。
2. **NIH 格式化**：门外像素置为 0（黑），再裁剪到 G 的外接矩形。NIH 原图本身就是贴合细胞外接框的矩形，所以不另设边距参数。
3. **其后与现有 A2 推理完全相同**：legacy_float_pr_od → 缩放到 128 × 128（与 NIH 一样，各向异性缩放）→ 归一化 → 模型。代码复用 c5b_infer.py 的路径，只在读入图像后插入第 1、2 步。
4. **单张回退**：门控回退（fallback = 1），或 G 的像素数少于裁剪面积的 3% 时，这张裁剪**不做门控**，用原图照常推理，并记录。这样每张裁剪都有分数，而且不用任何标签。
5. **NIH 验证折也走同一流程**（门控的 NIH 格式分支：黑像素 ≥ 5% 时前景 = 非黑像素）。这一点只用于判据 4，检查门控对源域是否接近恒等。

### C6：站点级 AdaBN（针对 W-K，不用标签）

- **文献**：Li, Wang, Shi, Liu, Hou, *Revisiting Batch Normalization For Practical Domain Adaptation*，arXiv:1603.04779（2016），期刊版 Pattern Recognition 80 (2018)。封存前由主会话核对书目信息。
- **做法**：权重全部冻结，只重估每个 BatchNorm 层的 running_mean 和 running_var。实现细节写死（实验管理 10-27 意见）：
  1. 先把整个模型设为 eval；
  2. **只把 BN 层**设为 train 模式，momentum = None（累计平均），并先调用 reset_running_stats()。模型其余部分保持 eval，Dropout 等不生效。
  3. 在 `torch.no_grad()` 下前向；
  4. 重估之后，**整个模型切回 eval** 再打分。
  - 不做 Tent 一类的熵最小化或任何梯度更新。
- **重估用的数据：按整视野抽样**（实验管理 10-27 意见：部署时站点交来的是一批视野，不是从全站随机抽出的细胞）。
  - 用 `default_rng([20261027, 6, 站点序号, seed, 抽样子序号])` 对该站点的全部视野做一次随机排列，主口径的抽样子序号为 0。
  - 按排列顺序整视野纳入，直到累计细胞数 ≥ 2,048 为止，纳入的视野数记为 K。
  - 选中视野中的**全部**裁剪都用于重估，不看标签。
  - 视野的定义沿用各站点 ids 文件中的 `field`。NIH 验证折的 `field` 是病人组。
  - 预计 K 约为 19–32，与 m = 22 同一量级。运行时按站点、seed、子序号记录 K 和实际细胞数。
  - 预处理与该配置的打分输入完全相同：C6 用原图，C1a + C6 用门控后的图。
  - 每个站点、每个检查点各重估一次，NIH 验证折也同样处理（判据 4 用）。
  - lb_same 和 Lacuna-B 重建版各自看作一个"站点"，分别从自己的裁剪中抽样重估。两者的阴性完全相同，阳性只是取景不同，各自重估才对应"该取景方式下的部署"。
- **模型核对**：MalariaNet 含 BatchNorm（证据：`forge_trunk.py` 的 `bn_frozen`）。fork 在写脚本前做两件事，任何一项不符就停：
  - 从 A2 检查点的 state_dict 列出全部 BN 层（名称、通道数、是否 affine），并核对 GRL 包装剥离后 BN 键齐全、running 统计存在；
  - 遍历全部模块，核对网络中**没有其他依赖 batch 统计或在 train 模式下行为不同**的层（如 InstanceNorm 的 track_running_stats、GroupNorm 以外的自定义归一化、Dropout 以外的随机层）。
- **与 S3 的关系**：
  - 重估不读标签；打分函数在 S3 抽样之前就固定下来。S3 的抽样、居中候选和认证逻辑一律不变；标签只被 S3 用一次。
  - 已知的弱耦合，照实披露：重估用到的 2,048 张图像，其中一部分可能落在 S3 抽中的视野里。这只是通过全站点的 BN 统计产生影响，不依赖标签。
- **TinyML 说明**（写进讨论，不作判据）：新统计可以折叠进卷积权重，得到每个站点一份权重；MCU 上的推理代价不变。

## 3. 事先写定的检查与停止条件

### 阶段 1：只算掩码，不打分（在 C1a 和 C1a + C6 打分之前）

对 BBBC-ALL、MP-IDB 新集、Lacuna-B 重建版、lb_same、NIH 验证折，逐张运行 `gate()`。

**输出（逐张）**：回退标志、门控像素数、G 的外接框、质心（换算到视野坐标）、门控后的 central_frac。

**报告**：
- 每个集合按类别分的回退率；
- 门控后 central_frac 的 q10 / q50 / q90；
- 每个开发站点每类随机 24 张的目检图（rng 种子 0：原图叠加 G 的轮廓，旁边放 NIH 格式化后的结果）；
- **同细胞一致率**：同一个细胞在 lb_same 与重建版两种裁剪下，G 的质心在视野坐标中相距 ≤ 0.5·R 的比例，R 取重建版 G 的等效半径。

**掩码合格判据**：每个开发站点（BBBC-ALL、MP-IDB、Lacuna-B 重建版）都同时满足：
- 回退率 ≤ 10%；
- 两类回退率之差 ≤ 5 个百分点；
- 目检图里明显分错的 ≤ 3/24（每类各看一次）。

"明显分错"是指 G 落在邻近细胞上、漏掉中心细胞一半以上，或把两个以上细胞并在一起。目检由主会话做，判定写进台账后才进入阶段 2。

**不合格时**：
- 任一开发站点不合格，C1a 和 C1a + C6 **不打分**，记为"掩码不合格，配置无效"。C6 照常进行。
- 下一步是修 P6 门控（属于 P6 的机制改动），不在本预注册内调门控参数。

**机制读数的前提**：同细胞一致率 ≥ 0.90。低于这个值时，机制读数照常报告，但标注"取景段受选错细胞混杂"。

### 阶段 2 之前：A2 还原核对

- **eval_a2**：沿用 C5b 的做法。用同一套 7 个评价脚本跑已有的 A2 logits，与已有 A2 结果相差 ≤ 1e−9，逐次抽样数组相等。
- **NIH 验证折复现**：在本次推理管线中，A2 不加任何改动推理 NIH 验证折，AUROC 与 `runs/eval/a2_s*_eval.json` 的 `nih_validation.auroc` 相差 ≤ 1e−4。
- 任一项不通过就停。

### C6 的抽样稳定性（事先写定）

- 除了主口径（抽样子序号 0），再用子序号 1–4 各重估一次，只计算三个开发站点和 NIH 验证折的 AUROC，不跑 S3 评价。
- **稳定**：每个站点、每个检查点，5 个子序号之间 AUROC 的极差都 ≤ 0.005。
- 不稳定时，即使四条采纳判据都满足，**该配置也不采纳**。理由是部署结果取决于碰巧抽到哪些细胞。这时记录"对抽样不稳定"，下一步的候选是增大 N，属于另一轮。
- C1a + C6 用同样的规则。

## 5. 判据（事先写定；三个配置各自独立判定）

### 采纳判据

沿用 C5b 的四条，口径为 A2、ε = 0.10、m = 22，对照为冻结 A2。必须同时满足：
1. BBBC-ALL 的 S3 实现灵敏度提升 ≥ +0.03；
2. 三个开发站点的平均提升 ≥ +0.03；
3. 三个站点的 S3 覆盖率都 ≥ 0.90；
4. NIH 验证折 AUROC 下降 ≤ 0.005。比较对象是"同一配置作用于 NIH 验证折"（C1a 门控 NIH，C6 用 NIH 验证折自身的细胞重估 BN），对照是冻结 A2 的已存值。

另外：C1a 和 C1a + C6 须通过阶段 1 的掩码合格判据；C6 和 C1a + C6 须满足抽样稳定。

### 判定规则

- 每个配置单独判定"有效 / 无效"，不先比较三者再挑一个去判。
- 判据按点估计判定；区间跨过阈值时，照实写"在抽样误差内不能确定"。
- **多个配置都有效时的选择规则**（事先写定，只在"有效"的配置之间使用）：
  - 默认选最简单的，顺序为 C1a、C6、C1a + C6；
  - 只有当更复杂的那个三站平均提升至少高出 0.01 时，才选更复杂的。
- **C1a 在阶段 1 掩码不合格时**，C1a + C6 一并作废，最终只判 C6。

### 机制判据（只用于归因，不决定是否采纳）

- **C1a、C1a + C6（取景）**：取景段（lb_same → 重建版，A2，ε = 0.05，S3 灵敏度）从 +0.076 降到 ≤ +0.038，而且 ci95 上界 < 0.076。满足时称"门控消除了大部分取景敏感性"。
- **C6、C1a + C6（类条件偏移）**：BBBC-ALL 上阴性分数相对"同一配置下的 NIH 验证折"的 KS 降到 ≤ 0.43（相对 A2 的 0.85 减半），而且 5 个检查点中至少 4 个满足。满足时称"站点级 BN 重估减轻了类条件偏移"。
  - A2 的 0.85 在本次运行中按同一口径重算，作为基准。重算值与 0.85 相差 > 0.02 时，以重算值的一半为门槛，并照实记录。
- **ε 的分工**：沿用 C5b 的写法。机制在 ε = 0.05 下测，采纳在 ε = 0.10 下判，两者不一致时照实报告，不改判据。

### 一并报告（不作判据）

- ε = 0.05 时的灵敏度和 ΔSens^own；
- 各站点的 AUROC；
- 三个站点的阴性 KS 和中位数平移；
- S3 的候选选择频率；
- 每个 seed 的结果；
- C1a 的单张回退率，以及门控后 central_frac 按类的分布。

ICC（s10）不做，与 C5b 相同（实验管理 10-27 同意）。

### 都无效时

先做根因分析，再按"不足 → 改动"提出下一组候选，交用户决定。
- 门控不合格，或同细胞一致率低：根因在 P6 门控。
- 取景段降了，但灵敏度没升：瓶颈不在取景。
- KS 降了，但 AUROC 没升：偏移不是 BN 统计能对齐的，比如形态差异，指向 C5a。
- KS 不降：说明 W-K 不在低层统计。

不调参重试。

## 6. 数据边界、资源与纪律

- **只读**：A2 检查点 s41–s45、三个开发站点、lb_same、NIH 验证折（用断言限定为验证折）。锁定测试折和确认站点都不读。
- **作业形式**：一个包装脚本，分两个阶段。阶段 1 只算掩码、出目检图，然后停；由主会话目检并写进台账，再由实验管理批准阶段 2。阶段 2 依次做还原核对、推理、check、评价。
- **资源**：按实验管理 10-27 定的上限。
  - 推理：Pss ≤ 7.5 GiB，显存 ≤ 1.5 GiB；评价每步 ≤ 0.6 GiB。
  - 8 线程，nice 19；MemAvailable ≥ 24 GiB 才启动；/data 使用率 ≥ 90% 就拒绝启动；输出分区剩余 ≥ 5 GiB。
  - 每次只缓存一个站点。
  - 写盘预计：阶段 1 ≤ 20 MB（逐张统计 npz，加 10 张目检图）；阶段 2 ≤ 120 MB（主口径约 3 × 25 个 logits 文件，加稳定性约 40 个，再加评价输出）。输出写到新目录 `runs/c1a_c6_<UTC>/`，不覆盖已有文件。
- **执行前冒烟（本地）**：
  - `gate()` 与 `run()` 的一致性检查（65 张，差 0）；
  - AdaBN 函数的单元测试：在合成小批上与手算的均值和方差一致；重估之后模型处于 eval；非 BN 参数逐位不变。
  - 多进程用 fake Pool.map 冒烟（VM 脚本审查清单）；
  - 包装脚本的冒烟要实际跑到其 sha 校验段。
- **结果处理**：结果只拉文件；执行方不打开结果、不打印数字。由主会话判读，先交实验管理，再交用户。
- **复现**：C1a 和 C6 的门控都是确定性的；C6 的抽样由上面的随机数种子决定。运行时记录 torch / CUDA 版本、各检查点和脚本的 sha，以及 BN 层清单。

## 7. 假设与风险

**可证伪的假设**
- **H1（C1a）**：把外部裁剪格式化为 NIH 格式后，取景段至少减半，开发站点的灵敏度提高，NIH 代价 ≤ 0.005。
- **H2（C6）**：站点级 BN 重估使 BBBC 的阴性 KS 减半、AUROC 提高，从而提高灵敏度。
- **H3（组合）**：两个机制针对不同的不足，组合后的提升不小于两者中较大的那个。只报告，不作判据。

**风险与读数**

| 风险 | 读数 |
|---|---|
| 门控在 BBBC 上分错（P6 第 0b 步旧版 EDT 掩码在 BBBC041 上目检约 4/24 分错；流式门控改用了"最亮十分位"背景估计，但在真实外部集上还没有目检过） | 阶段 1 的掩码合格判据 |
| 矩椭圆门控（k = 2.2）削掉不规则细胞或寄生虫所在的边缘，造成阳性漏检 | 阳性的回退率、目检图、MP-IDB 和 Lacuna-B 上 AUROC 下降 |
| 站点的批统计以阴性为主（π ≈ 3%），把阳性特征一起拉偏 | 任一站点 AUROC 下降 |
| 小模型的 BN 统计对抽样敏感 | 抽样稳定性检查 |
| 偏移来自形态差异（间日疟与恶性疟），而不是低层统计 | KS 降了，但 AUROC 不升 |
