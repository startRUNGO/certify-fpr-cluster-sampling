## 2. 机制改动（只替换 v3 第 4 步）

### 2.1 映射（前景像素；非前景像素取 od，与 E1a 相同）

- v3（A2‴，对照）：od′_c = r0′_c + s0′_c · (od_c − ref_c) / max(s_c, S_MIN)
- **F2 v3c**：g = exp( (1/3) Σ_c ln( max(s_c, S_MIN) / s0′_c ) )；od′_c = r0′_c + (od_c − ref_c) / g。
  - **不截断（κ = ∞，实验管理 2026-10-29 已定）**。
  - 护栏：任何样本（NIH case、开发站部署组或抽样）的 g 落在 [1/16, 16] 之外，就停下报告，不截断、不调整。
- **F1 v3s**：od′_c = r0′_c + (od_c − ref_c)，即 g ≡ 1。
- 第 1–3 步（prepare、sample_stats：RBC 参照池、τ = 0.75、ref、s、S_MIN = 0.0048）、第 5 步（F2._restore）、crop fallback 与 sample fallback（走 F3.apply 的 legacy 路径）：直接调用 v3 模块（1943ce98），一字不差。
- s0′、r0′：沿用附录 S0′ 的封存值（s0p.json 21e76a3f），不重算。

## 5. 判据（事先写定）

每个候选单独判；两个候选的判据完全相同。

### 5.1 采纳判据（必须同时满足；与路线 §2 原样相同，不放宽）

(a) A2‴ 封存预注册 §5.1 的四条，原样：ε = 0.10、m = 22，对照冻结 A2（含其 S3 来源阈值），逐次配对。
1. BBBC-ALL 的 S3 实现灵敏度提升 ≥ +0.03；
2. 三个开发站的平均提升 ≥ +0.03；
3. 三个站的 S3 覆盖率都 ≥ 0.90；
4. NIH 验证折 AUROC（5 个种子的均值）下降 ≤ 0.005，对照 A2 的 0.9721（A2 第 6 个 epoch 的 0.97194 作为第二参照一并报告）。

(b) BBBC 视野偏移恢复保持（A2‴ §5.2 的门槛，这里升为判据）：P1 ≥ 0.34，且 P2 ≥ 0.70。计算方法与 A2‴ 相同：D1 脚本 a2pp_d1_s3select.py（9f63db61），通过已审的适配器 a2ppp_d1_adapter.py（c7fa7195）派生。

(c) mh 组内损失：
- 定义沿用 T1b（a2ppp_t1b.py 76406a0a）。组 = E3 部署组；组内阳性、阴性各 ≥ 10 才算有效；损失_g = 5 个种子平均的 AUROC_g(A2) − AUROC_g(候选)。A2 分数取 T3 对齐后的冻结 logits（runs/a2ppp_t3_20261029T135502Z，MANIFEST 核对）。AUROC 用 judge 的秩公式（22dce988）。
- 要求候选的 mh 有效组损失中位数 ≤ 0.0906。这是 A2‴(v3) 的 0.1811 的一半。0.1811 的来源：T1b 输出 t1b.json（08400790）addon_report_only.mh_groups 的 5 个损失（0.1485 / 0.1811 / 0.2252 / 0.1458 / 0.2443）的中位数，与 diag_read（1dc7e003）mh groups 中 v3 列的 5 个值（0.1485 / 0.1811 / 0.2252 / 0.1458 / 0.2443）的中位数核对一致。判读脚本冻结前还要从这两个文件重算一次并断言相等。
- 同时要求 mh 总体 AUROC（P-part 总体分数）的 5 种子均值 ≥ A2 的 5 种子均值 − 0.02。A2 为 T3 对齐 logits 的总体 AUROC。

(d) mh 5 个种子的总体 AUROC 跨度（最大值减最小值）≤ 0.05。

按点估计判定；区间跨过阈值时照实写"在抽样误差内不能确定"，判定仍按点估计（与 A2‴ 相同）。

### 5.2 选择规则
