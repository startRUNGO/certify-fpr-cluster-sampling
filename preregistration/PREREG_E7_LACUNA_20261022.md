## 1. 子站点（一张图像 = 一个视野 = D3 单位）
Lacuna-A：1920×1080 图像（500 张，圆形视场）。Lacuna-B：4032×3016 图像（499 张）加 4 张 4160×3120 图像（计数中单列这 4 张，分析中并入 B）。不使用时间戳 ID 作玻片代理。

## 2. 阳性
对“Parasitized cell”框裁剪。Trophozoite 或 Gametocyte 框若与某个 Parasitized 框 IoU ≥ 0.3，或其面积落在该 Parasitized 框内的比例（交集面积 / 该 Trophozoite 或 Gametocyte 框面积）≥ 0.8，则并入该 Parasitized 框（不另裁）；否则作为独立阳性裁剪。排除 WBC 与 Artifact。每边外扩 5 像素并截断于图像边界（同 BBBC041 协议），存为无损 PNG，再经与既有评估相同的缩放与预处理（PIL 双线性缩放到 128×128，A2–A4 前端为 legacy_float_pr_od 先于缩放）。

## 3. 阴性（未标注红细胞；经典检测，无学习）
**执行口径（检测器；参数事先固定，不得按结果调整）**：
- 每个子站点的参考半径 r0 = 该子站点全部 Parasitized 框 (w+h)/4 的中位数（像素）。
- 每张图像缩放到使 r0 约为 20 像素（比例 s = 20/r0，双线性），取绿色通道，高斯平滑（σ = 2 像素，缩放后），cv2.HoughCircles（HOUGH_GRADIENT，dp = 1，minDist = 20，param1 = 100，param2 = 25，minRadius = 12，maxRadius = 28，均为缩放后像素）；检测结果映射回原分辨率，检测框 = 以圆心为中心、边长 2r 的正方形。
- 视场掩码：灰度图（三通道均值）取阈值 > 40，保留最大连通域并填洞，得到视场；某检测保留为阴性须同时满足：与每个标注框（任何类别）的 IoU < 0.1；整个半径为 2r 的圆盘落在视场之内（即圆心到视场边界的距离变换值 ≥ 2r，对应“整体在视场内并留 1 个半径的边距”；对 Lacuna-A 即圆形光圈内，对 Lacuna-B 同样适用以排除暗角）；其圆心与已保留的另一检测圆心的距离 ≥ 1 个半径（按累加器得分从高到低贪心保留，半径取当前检测的 r）。
- 检测器质量：Parasitized 框中被某个（保留前的）检测以 IoU ≥ 0.5 匹配的比例（召回），分子站点报告。
- 报告：阴性总数、每张图阴性数的分布（最小/四分位/中位/最大）、含 ≥2、≥5、≥10 个阴性的图像数。
- 标签噪声（未知，列为局限）：若“阴性”中有比例 η 实为感染，则实际 FPR 至多被高估 η；报告 η ∈ {0, 0.01, 0.02, 0.05} 下的实际 FPR（下界 max(0, FPR_obs − η)），并在 E7-2 中同时报告 η=0 与 η=0.05 两个口径的覆盖率。
- 另做检查图：A2 seed 41 下得分最高的 100 个“阴性”的裁剪网格，留待专家复核；不由我们标注。
- 裁剪缓存于 <DATA>/p5_e7_lacuna/crops/，清单（CSV）记录：视野 ID（图像文件名）、框或检测编号、子站点、类别（positive_*/negative）、框坐标。
