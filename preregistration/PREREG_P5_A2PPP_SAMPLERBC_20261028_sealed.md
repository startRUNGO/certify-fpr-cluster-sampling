## 2. 机制改动

### 2.1 前端 v3 `sample_rbc_iqr_float_pr_od`（新文件；legacy、fgref v1、v2 都不改）

样本 S 是一组裁剪（定义见 §2.2）。对 S：
1. od、fg 与 v2 相同（fg 为 P2 前景，sha c5d09199）。100·|fg_i| < H·W 的裁剪不进入合并，自身按 legacy 处理（同 v2 回退规则）。
2. F_S = S 中所有非回退裁剪的 fg 像素；ō = (od_R + od_G + od_B)/3；R_S = { p ∈ F_S : ō_p ≤ Q_0.75(ō over F_S) }（np.quantile，linear）。三通道共用 R_S。
3. ref_S,c = median(od_c over R_S)；s_S,c = q75 − q25（np.quantile，linear）。
4. 对 S 中每个非回退裁剪：z_c = (od_c − ref_S,c) / max(s_S,c, s_min)，od′_c = s0′_c · z_c。
5. 截断与 restore 同 v2（fgref_iqr_prod.py:130–133，无回加项）。
6. S 中没有任何非回退裁剪时，整个样本按 legacy 处理，计数并报告。

**常数（事先写定）**
- s_min = 0.0048（同 A2″ §2.1）；τ = 0.75（规格 §2.4，设计理由，不按数据调）。
- s0′_c：NIH **训练折**全部 case，逐 case 按第 1–3 步算 s_case,c，取按 case 的中位数。不抽样，不用标签。写成本预注册的附录 S0′，在新 M0 的任何结果之前封存。A2″ 的 s0（3d04873f）不沿用。

### 2.2 样本的定义（已定 P）

- NIH 训练折、NIH 验证折：样本 = case（split_cases_greedy 的 case_id），两者一致。NIH 锁定测试折照旧不开。
- 开发站点：样本 = S3 的这一次抽样（m 个 field 的全部裁剪，不用标签）。抽样按 rev1 的 RNG 重放（key [20261022, key8, ai, seed, m, sidx]，BBBC 8/0、mh 31/0、lh 8/2），与 A2 的抽样逐次配对。每次抽样重算统计量、重新推理。
- **等价检查（smoke 必过项）**：P 通路把统计量固定为站点级时，输出逐位等于站点级的直接实现。

### 2.3 训练配置

同 A2″ §2.2：从 B0_s 继续 6 个 epoch，种子 41–45，固定取第 6 个 epoch，串行，只换前端。训练时 NIH 裁剪按其 case 的样本统计量做 v3（统计量在训练开始前一次算好，逐 case 存表并记 sha）。

**前端与增强的先后顺序（事先写定）**：A2″ 的训练入口 code/p5_a2pp_train.py 中，`__getitem__` 的顺序是
- 第 97 行：`raw = Image.open(self.root / s.path).convert("RGB")`，读原始像素；
- 第 98 行：`fgref_iqr_float_pr_od(np.asarray(raw, dtype=np.uint8), self.s0)`，前端作用在**未经任何增强的原始像素**上；
- 第 99 行：`apply_pseudo_site(img, seed=..., epoch=..., sample_id=...)`，伪站点（光度类）增强在前端**之后**；
- 第 100 行：`self.tf(r.image)`，即 `tx(128, True)`（第 90 行），几何变换与缩放也在前端之后。

所以前端之前没有任何光度类增强。A2‴ 保持同序，只把第 98 行换成前端 v3。case 统计量取**未增强的原始像素**（与第 97 行读入的像素相同，同一 P2 前景），与实际进入前端的像素一致；增强只作用在前端输出上，与 A2″ 相同，不影响统计量。训练入口的 diff 必须保持这一顺序，审查时逐行核对。

### 4.3 NIH case 级捷径关卡（训练折；规则先于读数写定）
- 感染 case：训练折中至少有一张 Parasitized 裁剪的 case；其余为未感染 case。
- 度量：6 个 case 级统计量（s_case,R/G/B、ref_case,R/G/B）各自的单变量 AUROC，A′ = max(A, 1 − A)；A* = 6 个 A′ 的最大值。不拟合模型。
- 报告训练折中感染 case 与未感染 case 的数量。
- **规则**（先于读数写定）：
  - 任一类 case 少于 10 个 → AUROC 不可判，停，回实验管理；
  - 否则 A* ≤ 0.70 → 继续；A* > 0.70 → 停，回实验管理决定，主会话不得自行改。
- 与 §4.2 用同一次计算的 case 统计量。
