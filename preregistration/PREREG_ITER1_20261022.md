## 1. S2：M_b 自参照工作点
- 分数 s = logit1 − logit0（来自保存的逐样本 logit）。
- 每组 g（NIH 视野图 / BBBC 原图 / MP-IDB 图像）：τ_g = median(s_g) + c·MAD(s_g)，MAD 取未缩放的中位绝对偏差（不乘 1.4826）；组内细胞数 < 10 的组不报告 M_b 阈值，退回源 Youden 阈值，并单列退回比例。
- c 只在源端估计：NIH 验证折（校准折）内、仅用未感染细胞所在的组：对每个含 ≥10 个细胞的视野图组，计算 z_i = (s_i − median(s_g)) / MAD(s_g)（组内全体细胞的中位数与 MAD），取该组所有未感染细胞的 z_i，合并所有组后，取使合并未感染细胞 FPR = 5% 的 z 分位数（第 95 百分位）为 c。不使用锁定折与任何外部集。
- 对比（均在同一评估集、同一检查点）：源 Youden 阈值（既有口径）、M_b、oracle 阈值（目标标签，只作诊断，标 oracle）。
- 指标：平衡准确率、灵敏度、特异度；按组内感染比例分档（<5%、5–20%、>20%，用组内真实标签算比例，仅用于分档报告，不进阈值）。
- 检查点：A2 与 A0-ctrl 的 s41–s45。
- 判据（预先写定）：“M_b 改进”= 在 BBBC-ALL 与 MP-IDB 两个外部集上，M_b 的平衡准确率均不低于源 Youden 阈值，且至少一个外部集提高 ≥ 0.05（5 种子均值），NIH 锁定折上平衡准确率下降 ≤ 0.01。否则记“未改进”，如实报告失败原因（按分档给出），不改 c 的定义、不改分位数、不换阈值形式。
- 额外要求：BBBC-ALL 为类别极不平衡（寄生约 3%），平衡准确率与 AUROC 之外还报告组内阳性率分布；不因不平衡调整任何参数。

## 2. S3：M1 OD 尺度归一化（零训练）
- 变体 (a)：OD' = OD / median_fg(OD)；变体 (b)：OD' = (OD − median_bg(OD)) / median_fg(OD − median_bg(OD))，逐通道。fg = 细胞前景像素，bg = 背景像素；前景/背景用现有阈值规则（背景 = R+G+B < 12 的黑色像素，与既有诊断一致；其余为前景）；若某通道的 median_fg 为 0 或 bg 为空，该图退回 A2 前端并计数。
- 合成数据：在 invariance_check 基础上加浓度 s = 0.7 / 1.3，报告各变体相对基础图的输出残差（平均与最大灰度级），与 A2 前端对比。
- 检查点推理（零训练）：对冻结的 B0 与 A2 检查点（s41–s45）只改输入前端，报告：NIH 域内 AUROC 代价、BBBC041 原集/BBBC-ALL/MP-IDB 的 AUROC、源阈值与 oracle 阈值下的平衡准确率。
- 晋级续训条件（P4 会话已定）：两个外部站点 AUROC 都不下降，至少一个站点提高 ≥ 0.01，NIH 代价 ≤ 0.005（相对同一检查点未改前端的结果，5 种子均值）。满足则按 A2 协议续训 5 个种子（同一父检查点、6 轮、同超参），续训须另经用户同意；未满足则不续训，报告失败原因。
- 站点选择：晋级判定用 BBBC-ALL 与 MP-IDB（不用已被原集尺寸偏差污染的 bbbc041_cells 与匹配子集作判据，仅对照报告）。
