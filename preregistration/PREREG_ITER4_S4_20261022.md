# P5 迭代 4 预注册：S4（少量阴性标注校准）与负结果证据包

写于 2026-10-22，早于任何 S4 数字。设计：P4 会话；执行口径补全：P5 会话（标“执行口径”）。母文件：PREREG_ITER1_20261022.md（143a07d4…a4a4d）、PREREG_ITER1_ADDENDUM_S3S2b_20261022.md（266da7fb…8e3a）、PREREG_ITER2_S2c_20261022.md（0dda7bb0…0db9）、PREREG_ITER3_S2d_20261022.md（ecd4f6ec…6e934）。CPU only，只读已保存的逐样本 logit（runs/iter1_20261021/infer），分数 s = logit1 − logit0；不训练、不用 GPU。

## 1. 设定
每个目标站点由技术员标注 n 个未感染细胞（只用阴性标签，不用阳性标签）。n ∈ {5, 10, 20, 50}，每个 (站点, 检查点, 种子, n, 设计) 随机抽 200 次，两种抽样设计：
- D1：n 个阴性分布在 n 张不同的图像上，每图 1 个；
- D2：n 个全部来自同一张图像（单张玻片的现实情形）。
**执行口径**：D1 先在含 ≥1 个真阴性的图像中无放回抽 n 张，再在每张中随机抽 1 个真阴性；D2 先在含 ≥n 个真阴性的图像中随机抽 1 张，再从中无放回抽 n 个真阴性；若该站点没有含 ≥n 个真阴性的图像，D2 在该 n 记 n/a。图像：NIH 视野图 / BBBC-ALL 原图 / MP-IDB 图像。随机数：numpy default_rng([20261022, 检查点序号, 训练种子, n, 设计序号, 站点序号])；同一抽样用于全部四个估计量（配对）。

## 2. 估计量（名义 FPR α = 5%）
- E1 经验：τ = 该 n 个得分的 0.95 分位数（numpy 线性插值）。
- E2 共形：τ = 第 ⌈(n+1)·0.95⌉ 个次序统计量；n < 19 时该值超过 n，取最大值。
- E3 形状迁移：τ = median_n + IQR_n·Q0*(0.95)；Q0* 为 NIH 验证折阴性经居中形状的标准化 0.95 分位数（每个视野图按其未感染细胞中位数居中，再按自身中位数与 IQR 标准化；每个检查点各自估计，同 S2d 第 2 节形状）。IQR_n 用 numpy 线性插值四分位数。
- E4 收缩：τ = w·τ_E3 + (1−w)·τ_source，w = n/(n+n0)，n0 = 10 固定；τ_source 为 NIH 验证折 Youden 源阈值。

## 3. 评估与报告
站点：BBBC-ALL、MP-IDB、NIH 锁定折（对照）。检查点：A2 与 A0-ctrl 的 s41–s45。每个 (站点, n, 设计, 估计量) 报告：在**其余全部真阴性**（去掉被抽中的 n 个）上的实际 FPR（均值与 90 百分位）、灵敏度（全部阳性）、平衡准确率（均值 ± SD）；同行列出源阈值与 oracle（**执行口径**：源阈值与 oracle 的指标在站点全部细胞上算一次，不随抽样变化；oracle 标注，只作诊断）。**聚合口径**：每个检查点先把 5 个种子 × 200 次抽样合并（共 1000 次）；均值为 1000 次的均值，SD 与 90 百分位在 1000 次上算；检查点（A2、A0-ctrl）分开列。

## 4. 成功判据（预注册）
对 A2，在 n = 20、D1 下，存在同一个估计量同时满足：BBBC-ALL 的平衡准确率均值 ≥ 源阈值 + 0.05；MP-IDB 的平衡准确率均值 ≥ 源阈值；两站点的实际 FPR 90 百分位 ≤ 0.10；NIH 锁定折平衡准确率均值下降（源阈值 − 估计量）≤ 0.01。并报告：每个估计量满足上述判据的最小 n（在 {5, 10, 20, 50} 中，D1，A2）；D2 惩罚 = D1 的平衡准确率均值 − D2 的（n = 20 及各 n）。不改判据，不因结果调整 n0、n 取值、分位方法。
