## 4. 要回答的问题和事先写定的读法

**Q1：认证是否仍然成立（主问题）**
- A2、(0.10, 0.10)、m = 22 下，S3 在新集上的覆盖率 ≥ 0.90：称"取景一致后，MP-IDB 上的 FPR 认证仍然成立"。
- 覆盖率 < 0.90：如实报告为 S3 在开发站点上的失败；P5 中"所有站点覆盖率 ≥ 1 − δ"的表述必须修改。

**Q2：灵敏度的结论是否受取景影响**
- 比较 S3 在新旧两集上的 ΔSens_ε、ΔSens^own 和实现灵敏度。
- 读法：|新 − 旧| ≤ 0.05，称"MP-IDB 上的灵敏度结论对取景稳健"；> 0.05，称"旧集上 MP-IDB 的灵敏度数字含有取景混杂"。
- **不论哪种情况，P5 中 MP-IDB 的全部数字都改用新集**（见 Q4），旧集只在补充材料中保留，并附取景说明。这一条在看到结果之前就写定，不依赖结果。

**Q3：P5 的 MP-IDB 机制是否成立**
- 原稿的说法是：视野阳性比例高，所以中心化会增加视野间差异、ICC 上升，S3 在 MP-IDB 上多数抽样选 c0（`s11_results/a2|mpidb_full|22|S3|0.1|sel_freq|c0` = 0.603）。
- 第一个条件（视野阳性比例中位数 < 0.30）在新集上**已知成立**（中位数 0.043，见第 1b 节），只是数据描述，**不算检验**。
- **待检验的条件只有一个：** A2、ε = 0.10、m = 22 时，S3 在新集上选 c0 的比例。
  - < 50%：称"原稿的 MP-IDB 机制（高阳性比例 → 选 c0）是旧集抽样留下的假象"，改写该段。
  - ≥ 50%：称"阳性比例回到自然水平后，S3 仍然多数选 c0，原解释不足以说明这一点"，同样改写该段，改为如实报告新集上的 ICC 和选择频率，不再用阳性比例来解释。
  - 阈值取 50%，是因为原稿的说法是"多数抽样选 c0"，50% 正是"多数"的分界。

**Q4：怎样替换**
- 新集取代旧集，作为 P5 的 MP-IDB 开发站点。
- 所有引用 `mpidb_full` 的数字都按新集重算。旧集的结果全部保留在补充材料里，并写明取景差异。
- 来源阈值调查、比较链（R1-all → B1 → B1u-c0 → B1u-c1s → S3）和 S3-G 都一并替换。

**不重新调参、不重新选门槛、不改 S3**：看到新集的数字之后，S3、候选集、门限和判据一律不改。

**Q5：来源阈值的 FPR 膨胀（调查）**
- 35 个检查点在来源阈值（NIH 验证折的 Youden 阈值，读取已存档的值）下，于新集上的实现 FPR。报告：中位数、超过 0.10 和超过 0.20 的检查点比例，以及 AUROC 与 FPR 的 Spearman ρ（口径与 5.1 节的其他站点相同）。
- 读法事先写定：35 个检查点的 FPR 中位数 > 0.10，称"MP-IDB 上存在膨胀"；否则称"不存在"。原稿的表述是"MP-IDB 上没有检查点超过目标"，按新结果照实替换。

**Q6：Table 3 的无标签校正在新集上重算**
- 照 `rev5.py`（REV-5，PREREG_REV_UNLABELED_20261023.md，sha de5e3960…）的定义，对来源阈值、两种 UPA（源流行率、真实流行率）、流行率约束分位数，以及 Table 3 列出的其余无标签校正，在新集上计算实现 FPR 和灵敏度。判据沿用原判据，即 ITER1–3 和 REV-5 中与其他站点相同的那一套，不新定。
- **站点限定：** 改编后的脚本只处理新 MP-IDB 一个站点。原 rev5.py 的站点列表里有 `nih_locked_test`，改编版**必须删去**，断言不读任何 NIH 文件。

**Q7：依赖视野规模和站点组成的其余数字**

**限定语（写进稿件 4.2 和 6.2）：** 新集只保留不重叠的单个细胞，因此在新集上认证的是**孤立细胞的 FPR**。真实部署中，处在重叠细胞团里的细胞也会进入复核队列，它们的误报不在这个认证之内。另外，约 12.6% 的寄生虫因宿主处在重叠细胞团中而没有进入新集，阳性群体偏向"容易"的那部分。这会影响灵敏度和 AUROC，不影响覆盖率。
