## 三个上界（单边，水平 δ，站点 FPR p = ΣX_i/Σn_i）
记 N = Σn_i，n̄_w = Σn_i²/N，p̂ = ΣX_i/N。
- **B1（Kish 有效样本量 + Clopper–Pearson）**：ICC^ 为同一 m 个视野的单因素 ANOVA 估计（不等容量）：n0 = (N − Σn_i²/N)/(m−1)；MSB = Σ n_i(p̂_i − p̂)²/(m−1)；MSW = Σ n_i p̂_i(1−p̂_i)/(N−m)，p̂_i = X_i/n_i；ICC^ = (MSB − MSW)/(MSB + (n0−1)MSW)，截到 [0,1]；分母为 0 时 ICC^ = 0（执行口径）。n_eff = N/(1 + (n̄_w − 1)·ICC^)；有效超出数 x_eff = ΣX_i·n_eff/N。上界 = Beta(1−δ; x_eff+1, n_eff − x_eff) 分位数（对非整数计数的 Clopper–Pearson 连续化；执行口径）。
- **B2（Beta-二项）**：对 m 个视野的 (X_i, n_i) 以最大似然拟合 (p, ρ)，a = p(1−ρ)/ρ，b = (1−p)(1−ρ)/ρ；上界 = 使剖面似然 2(ℓ_max − ℓ_prof(p)) ≤ z²_{1−δ}（z = Φ⁻¹(1−δ)，即 χ²₁ 单边截断）的最大 p（p ≥ p̂ 侧）。**执行口径（数值）**：ρ 取 48 点 logit 等距网格，ρ ∈ [1e-4, 1−1e-4]；p 取对数加密网格并在括号内二次加密，线性插值求交点；ℓ_max 取同一网格上的最大值；若网格最大 p（0.99）处仍未越过截断则上界取 1。先用 scipy 全优化在合成数据上核对数值误差（只核对，不改规则）。
- **B3（聚类稳健比率估计）**：UCB = p̂ + t_{m−1,1−δ}·SE，SE² = Σ(X_i − p̂ n_i)² / (m(m−1) n̄²)，n̄ = N/m。X_i ≡ 0 时 SE = 0（UCB = 0）；按规则如实使用，不作修补。

**性质声明（须随结果一同标注）**：B1、B3 为渐近/近似保证（B1 依赖 ICC 的插值估计与设计效应近似；B3 依赖 t 近似与线性化方差），B2 为模型依赖保证（假设 Beta-二项且 χ²₁ 渐近）。三者**都不是有限样本保证**。覆盖率是对真实站点（有限总体）的经验评估，不是定理。
