## 1. 源端形状（每个检查点，只用 NIH 验证折）
F0 = 验证折未感染细胞得分的经验分布，F1 = 寄生细胞的。各自按自己的中位数与 IQR 标准化：z0 = (s − med0)/IQR0，z1 = (s − med1)/IQR1。f0、f1 为标准化样本的高斯 KDE，带宽取 Silverman：h = 0.9·min(sd, IQR/1.34)·n^(−1/5)。**执行口径**：f0、f1 在 2048 点等距网格上预先算好（网格范围 [min−5h, max+5h]），按线性插值查值，网格外密度取 1e−12。Q0(·) 为 z0 的经验分位数。

## 2. 站点模型与拟合
目标站点的全部无标签细胞（不用任何标签）：p(s) = (1−π)·f0((s−a0)/b0)/b0 + π·f1((s−a1)/b1)/b1。五个参数 (π, a0, b0, a1, b1) 用最大似然拟合：L-BFGS-B，参数化 (π, a0, d = a1 − a0, ln b0, ln b1)，箱约束 π∈[0, 0.95]、d≥0、b>0（ln b 取 [−10, 10]）。
- 初值：a0、b0 = 得分较低一半的中位数与 IQR；a1、b1 = 得分最高 10% 的中位数与 IQR；π = 0.2。
- 5 次重启，保留似然最大者。**执行口径**：第 1 次用上述初值；第 2–5 次依次令 π = 0.05、0.1、0.3、0.5，a0、b0、a1、b1 各乘以 exp(N(0, 0.2²))，随机数种子固定为 20261022（numpy default_rng）。
- 数值梯度；最大迭代 500 次。

## 3. 阈值
τ_site = a0 + b0·Q0(0.95)（目标 5% FPR）。退化保护：若 π̂ < 0.005 或 (a1 − a0)/b0 < 1，改用仅阴性拟合（π = 0，只拟合 a0、b0，同样的 ML 与重启）后的 τ = a0 + b0·Q0(0.95)。报告每个集、每个检查点族中退化情形出现的比例。

## 4. 并列报告的变体
(i) S2c 站点级（上述）——**主变体**；
(ii) S2c-group：τ_g = τ_site + w_g·(median_g − median_site)，w_g = n_g/(n_g + n0)，n0 = 50 事先固定，median_site 为站点全部得分的中位数（**执行口径**：“shrunk by w_g”解释为对组内中位数偏移乘 w_g；组 = NIH 视野图 / BBBC-ALL 原图 / MP-IDB 图像）；
(iii) 站点级 S2：τ = median_site + c·MAD_site（MAD 为未缩放的中位绝对偏差），c 取 S2 的校准值（每个检查点各自的 c，见 runs/iter1_20261021/s2/s2_mb_results.json）；
(iv) 源 Youden 阈值与 oracle 阈值（oracle 标注，只作诊断）。
