## B. S3：M1 OD 尺度归一化——口径澄清（覆盖母文件 §2 的对应部分）
1. 逐通道 c：o = −log10((I+1)/256)（float32，在裁剪后、缩放前的原分辨率上）。
2. 前景/背景（**偏离母文件的 R+G+B<12 规则，理由：BBBC041 与 MP-IDB 的裁剪几乎不含黑色像素，该规则会令背景为空、(b) 几乎全部退回**）：令 S = Σ_c o（三通道 OD 之和）；背景 bg = S 最小的 10% 的像素（最亮）；bgmed = median(S[bg])；前景 fg = {S > bgmed + 0.15}。若 |fg| < 50，该图退回，逐集、逐变体报告退回比例。
3. 变体 (a)：o'_c = o_c · ρ_ref,c / median_fg(o_c)。变体 (b)：o_b,c = o_c − median_bg(o_c)（bg 像素上的逐通道中位数），o'_c = o_b,c / median_fg(o_b,c) · ρ_ref,c。median_fg 为 0 的通道使该图退回。
4. 还原：I'_c = clip(⌊256·10^(−o'_c) − 1⌋, 0, 255)（uint8）。
5. ρ_ref,c：仅用 NIH 训练折图像（split_seed=42），取每图 median_fg(o_c)（变体 (a)）或 median_fg(o_b,c)（变体 (b)）的均值（退回图像不计入）；分别给 (a)、(b) 各一组。
6. 与检查点的组合：B0（原图训练）只做上述缩放步骤；A2 先做上述缩放，再做原 PR-OD 中值减法（legacy_float_pr_od），再缩放到 128×128、标准化。退回图像：A2 退回为原 A2 前端（即只做 PR-OD）；B0 退回为原图（不缩放）。
7. 检查点：B0 s41–s45 与 A2 s41–s45；基线为同检查点未改前端的既有推理（批量 512）。
8. 晋级判据（母文件 §2 不变，判定集改为 BBBC-ALL 与 MP-IDB）：两个站点 AUROC 都不下降，至少一个站点提高 ≥ 0.01，NIH 代价 ≤ 0.005（相对同一检查点未改前端，5 种子均值）。未满足则不续训。续训另须用户同意。

## C. S2b：污染校正的下尾估计（只用已保存的逐样本 logit，CPU）
分数 s = logit1 − logit0。每组（NIH 视野图 / BBBC-ALL 原图 / MP-IDB 图像）：
1. 阴性得分建模为位置 m、尺度 σ；π 为组内阳性比例，初值 π = 0。
2. 最多迭代 20 次，直到 |Δπ| < 1e-3：
   - a = 0.10·(1−π)，b = 0.40·(1−π)；Q_a、Q_b 为该组全部得分（混合）在水平 a、b 的分位数（线性插值）；
   - σ = (Q_b − Q_a)/(z_0.40 − z_0.10)，m = Q_b − z_0.40·σ（z 为标准正态分位数）；
   - τ_g = m + c·σ；f = 该组得分 > τ_g 的比例；
   - **主变体（偏差校正）**：π = min(0.9, max(0, (f − 0.05)/(1 − 0.05)))，0.05 为校准 FPR；
   - 次变体（字面）：π = min(0.9, f)。
3. 不迭代变体（π 固定为 0，分位水平 0.10/0.40，单次计算）作为第三个变体，使校正效应可分离。
4. c 的校准（P4 会话决定 4）：在 NIH 验证折中**不含阳性细胞且细胞数 ≥ 10 的视野图组**上，用不迭代估计量算 z = (s − m_g)/σ_g，对这些组的全部细胞合并，取第 95 百分位为 c；迭代版与不迭代版用同一个 c（A2 与 A0-ctrl 各自按检查点估计）。
5. 细胞数 < 10 的组、或 σ ≤ 0 的组，退回源 Youden 阈值，报告退回比例。
6. 判据同母文件 §1：在 BBBC-ALL 与 MP-IDB 上平衡准确率均不低于源阈值、至少一个提高 ≥ 0.05、NIH 锁定折下降 ≤ 0.01（5 种子均值）。主变体为判定变体，其余两个只作对照，不参与判定。
7. 额外报告（P4 会话要求 C）：各集按组内阳性率分档（<5%、5–20%、>20%）的灵敏度、特异度、平衡准确率；估计 π（迭代终值）对真实组内阳性率的平均绝对误差（每集）；三个变体并列。
8. 检查点：A2 与 A0-ctrl 的 s41–s45。
