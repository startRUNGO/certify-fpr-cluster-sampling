# 勘误：PREREG_P5_C5B_FRAMING_AUG_20261026.md（封存 a07deaf6…）

写于 2026-10-26。主会话检查了增强样例（20 张 contact sheet），此时还没有任何训练，也没有任何结果。原文不改。本勘误只改第 2 节中取景增强的实现细节，判据不变。

## 1. 中央细胞必须完整留在裁剪框内（两类相同）

- **问题**：样例中有阳性细胞的边缘被裁掉，寄生虫随之被切去一部分（POS #14–16）。NIH 没有寄生虫掩膜，这样裁剪后，标签可能已经与图像内容不符。
- **依据**：开发站点上测到的"偏心"，指的是细胞在裁剪框中占比低、周围带有更多背景和邻近细胞（旧 Lacuna-B 的阳性 = 标注框 + PAD，细胞是完整的），并不是细胞被截断。
- **更正**：采样裁剪框时，要求中央细胞的掩膜**完整**落在框内，不满足就重新抽样。阴性和阳性用同一条规则，以免引入"阳性从不被截断"这种与类别相关的取景线索。
  - central_frac 的范围 [0.50, 0.95] 和偏移上限 0.20 都保持不变，只是增加这一约束。实际能取到的偏移会因此变小，按实测的分布报告。
  - 如果重抽 50 次仍然不满足，这个样本不做增强，并记录原因；不增强的比例要报告。

## 2. 边缘片段改用完整细胞（仍然只取未感染细胞）

- **问题**：现在的实现是从其他细胞的掩膜内取一个矩形子窗口，样例中出现了硬边的矩形色块。真实的邻近细胞带有弧形的细胞边缘。
- **更正**：片段改为一个**完整的**未感染细胞（连同它的掩膜一起贴），放在裁剪框边缘，只露出一部分，露出的覆盖面积不超过 25%。来源仍然只能是训练折中 label = 0 的细胞，用断言写死。

## 3. 训练和推理的处理顺序一致

- **问题**：训练时，增强先把图缩放到 128 px，再做 PR-OD；推理时，是先在原尺寸上做 PR-OD，再缩放。
- **更正**：增强在原始分辨率上输出，裁剪框的边长按原始像素计；之后做 PR-OD，再由原有的 tx 缩放到 128 px。这与推理时的顺序完全相同。

## 4. 不变的部分

两个臂的设置、染色扰动、训练配方、评价、判据和读法都不变。冒烟要重做：重新渲染 20 张样例，并对 10,000 次抽样做范围检查，增加"中央细胞完整"和"片段边缘是弧形完整细胞"两项检查。
