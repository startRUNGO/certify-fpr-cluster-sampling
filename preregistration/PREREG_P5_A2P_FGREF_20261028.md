## 2. 机制改动

### 2.1 新前端 `fgref_float_pr_od`（新函数；legacy_float_pr_od 保留不动）

对一张 uint8 RGB 图像 I（H×W×3）：
1. od = −log10(I/256 + 1/256)，float32，与 legacy 完全相同。
2. 前景 fg = P6 门控的 P2 前景：`p6_streamgate_ref_v2.run` 中 P2 的语句，原样复制，并断言源文件 sha（c5d09199）。
   - 黑像素（max < 10）占比 ≥ 5% 时走 NIH 分支：fg = 非黑像素；
   - 否则：fg = 到 P1 背景色的 OD 距离上做 Otsu 后的前景。
   - 分支由图像本身决定，不看数据集名。所以 NIH 训练图（黑底）自然走非黑分支，站点裁剪走 Otsu 分支；被判进 NIH 分支的站点裁剪也按非黑处理，与 P6 §2.3b 一致。
   - **不用 fg_f（不做 N1 填洞），也不用 G（椭圆门控）**：(iii) 不依赖 P6 门控的目检结果。
3. 参照点 ref[c] = np.median(od[fg, c])，即每通道只在 fg 内取中位数，float32，偶数个样本时取平均，与 legacy 的 np.median 口径相同。
4. **回退（事先写定）**：|fg| < 0.01·H·W 时，ref 取整图中位数，即退回 legacy，并计数报告。
5. 其余与 legacy 相同：od − ref，截到 ≥ 0，restored = 256·10^(−od) − 1，截到 [0, 255]，转 uint8。

- **与 P6 端侧 P4 的关系**：P6 的 P4 在 G 内用直方图的下中位数构造 PR-OD 表；P5 这里是主机上的 float 实现，掩码用 fg 而不是 G。两者在概念上统一（参照点只取自细胞），**不逐位一致**。稿件中按此表述，不写"相同"。
- **为什么用 fg 而不用整图**：参照点只取自细胞，背景占多大比例、是黑是亮，从构造上都不再影响参照点，正对 R1′。

### 2.2 A2′ 的训练配置

- 只有一个臂，**A2′**：A2 的配方，只把前端从 legacy_float_pr_od 换成 fgref_float_pr_od。
- 不叠加一致性项，不做 framing 增强，一次只检验一个机制。
- 其余一律不变：伪站点（apply_pseudo_site，作用在前端输出之后，顺序与 A2 相同）、CDDG（自适应）、从 B0_s 继续、6 个 epoch、lr 3e−5（无 warmup，余弦退火）、wd 1e−5、bs 64、label smoothing 0.1；NIH 划分仍为 split_cases_greedy(seed = 42) 的 C 前缀 70/15/15。
- **种子**：41–45，各自从对应的 B0_s 继续，与 A2 一一配对（父检查点相同，只差前端）。封存即写定，不另换。
- **检查点**：一律取第 6 个 epoch 结束时的权重，不读验证折，不做选择，与 C5c 相同。A2 的"6 选 1"选择优势约 0.0001（C5c 预注册 §2 审查 M2），方向对 A2′ 不利，是保守的。
- **已知的不一致**：B0 是用 legacy 前端训练的。A2′ 从 B0 继续、换前端训练 6 个 epoch，前 1–2 个 epoch 可能有适应期。不为此加 epoch 或改学习率，列入局限。
- 判据 4 的第二参照 0.97194 是 A2 在 legacy 前端下的数值；A2′ 的数值在新前端下得到。两者都是"各自前端下的域内 AUROC"，口径一致。

### 5.2 采纳判据（与 C5c 相同，不放宽）

以 ε = 0.10、m = 22 为主口径，对照为冻结 A2（含其 S3 来源阈值），逐次配对。必须**同时满足**：
1. BBBC-ALL 的 S3 实现灵敏度提升 ≥ +0.03；

## 7. 假设、统计、复现、风险

**假设**
- 前提（M0，健全性，不是假设检验）：三个开发站点与 NIH 训练图的 W′ 之差都 ≤ 0.10。
- H1（效果）：M0 通过后，开发站点上 S3 的灵敏度提高，并满足采纳判据。
- H2（域内）：NIH AUROC 下降 ≤ 0.005。

**统计**：灵敏度差和覆盖率差与冻结 A2 逐次配对；paired_bootstrap_v2（818c1c31）给出 ci95、ci95_cluster 和 per_seed。M0 另报 W′ 差的 bootstrap 95% 区间（2,000 次，种子写死），不作判据。

**复现**：前端是确定性函数，没有随机量；训练随机量与 A2 相同，由 (seed, epoch, sample_id) 决定。运行时记录 torch / CUDA 版本和 B0 父检查点的 sha。

**风险与备选**
1. 前景掩码大面积出错（例如把背景整体当作前景）时，参照点会偏。读数：M0 的回退计数和 W′ 分布；出现时根因分析，不现场改掩码。
2. 训练侧（NIH，非黑像素）和部署侧（站点，Otsu 前景）的掩码定义不同，本身可能残留一部分参照偏移。M0 的 0.10 就是用来检查这一点的。
3. NIH 上细胞内部变白的比例会从约 86% 大幅下降，NIH 上的输入分布会变；由判据 4 检查。
4. B0 与 A2′ 的前端不一致（§2.2），列入局限。
5. A2′ 不被采纳时：先做根因分析，不调回退阈值、不换掩码、不加 epoch 后重训。
