## 标注单元
完全标注视野：技术员在一个视野里只标出少数感染细胞（点击数 = 标出的阳性数），该视野其余全部细胞成为已标注阴性。抽取 m 个视野（i.i.d.，从全部视野中无放回均匀随机），连同其全部细胞。**m ∈ {3, 5, 10, 22}（P4 会话原设计）；执行口径：加入 {30, 50} 作扩展，使“满足判据的最小 m”可回答。** 点击数（=所抽视野内的阳性数）与已标注阴性数逐格报告。Lacuna-B 的“阴性”是检测器给出的未标注红细胞（保留 η 界：并列报告 η=0 与 η=0.10 下界口径）。

## 规则 C1（视野聚类的 Learn-then-Test 认证）
- 候选阈值网格：所抽视野内已标注阴性得分的合并；**执行口径**：取该合并样本 j/200 分位（j=0,…,199，即从最大值向下）共 ≤200 个互异值，降序检验（固定序列检验）。判为阳性：s ≥ τ。
- 对每个 τ：每视野的超出数 X_i(τ) = 视野 i 的已标注阴性中 s ≥ τ 的个数，n_i = 视野 i 的已标注阴性数；细胞加权的站点 FPR = ΣX_i/Σn_i（总体 = 站点全部视野）。
- 检验 H_τ：FPR(τ) > ε（单边上置信界，视野为 i.i.d. 单元）。主界（Waudby-Smith–Ramdas 下注界）：Z_i = (X_i − ε·n_i)/n_max，**n_max = 该站点任何视野中的最大阴性数（总体常数，假定为已知上界）**；V_i = 1 − ε − Z_i ∈ [0,1]，对原假设 E[V] ≤ m0 = 1−ε 做预测下注检验（PrPl-EB 下注：λ_i = min(√(2 ln(1/δ)/(σ̂²_{i−1}·i·ln(1+i))), c/m0)，c = 1/2，μ̂_i = (1/2+ΣV_j)/(i+1)，σ̂²_i = (1/4+Σ(V_j−μ̂_j)²)/(i+1)；资本 K = Π(1+λ_i(V_i−m0))；视野随机顺序；K_m ≥ 1/δ 则拒绝 H_τ，即认证 FPR(τ) ≤ ε）。副界（Maurer–Pontil 经验 Bernstein）：W_i = 1 − V_i = Z_i+ε ∈ [0,1]，上界 mean(W) + √(2 s²_W ln(2/δ)/m) + 7 ln(2/δ)/(3(m−1)) ≤ ε 时拒绝（s²_W 为样本方差）。
- 沿降序网格继续检验，只要仍被拒绝就继续降低 τ，遇到第一个未被拒绝的 τ 即停；输出最后一个被拒绝的（最低的）τ。若最高网格值就未被拒绝，输出“cannot certify”并使用最高网格值。报告每种情形的频率。
- 保证目标：(ε, δ) = (0.10, 0.10) 与 (0.05, 0.10)。

## 规则 C2（含灵敏度的选择）
在被认证的阈值（固定序列中全部被拒绝者，构成降序网格的一个前缀）中，选使已标注阳性上估计灵敏度最大者。**执行口径与说明**：已标注阳性的灵敏度对 τ 单调不增，所以最大灵敏度必在前缀的最低 τ 取得（并列取最低 τ），因此 C2 与 C1 输出相同；固定序列检验的前缀结构使该选择保持与 C1 相同的保证（选择只在被拒绝的前缀内、且不再检验新的假设）。C2 仍如实运行并报告，若与 C1 在任何抽样上不同则报告差异。

## 等工作量基线
- R1-2：在同样 m 个视野中，每视野随机取 2 个已标注阴性，对 2m 个得分用 R1（(ε, δ) 下最小 k 使 I_ε(n−k+1,k) ≥ 1−δ，n=2m；不存在则取最大值并标记 too small）；
- R1-all：对 m 个视野的全部已标注阴性（Σn_i 个）当作 i.i.d. 直接用 R1（展示聚类失效）；
- R1-field：对每视野的全部已标注阴性取最大值，得 m 个统计量，对其用 R1（n=m，ε_img=ε）。
