## 1. 测到的不足（第 1 步，事先写定的判据已触发）

- 测量结果：`runs/lacuna_frame_20261025T120905Z/lacuna_frame_B.json`（sha256 6be13a60…）。PID 705994，峰值 RSS 0.26 GiB。
- 留出集（tuning == 0）的中心细胞掩码占比中位数：阳性 0.617，阴性 0.789，差 **0.172 > 0.05**，判为"取景与类别相关"。包含调参图在内的全部裁剪，差为 0.172，结论相同。
- 裁剪边长中位数：阳性 237 px，阴性 195 px。阳性是数据集的标注框，阴性是 Hough 检测器框。
- **目检**（主会话判读，两类各 24 张）：
  - 阴性框更紧，细胞几乎占满，常把细胞边缘切掉；有几张检测器把中心放在了两细胞之间，或框住的是中心淡染区那一圈。
  - 阳性框四周留有血浆边。
  - Lacuna 是恶性疟，被感染的红细胞不会胀大，所以框大约 22% 是取框方式本身造成的差别，不是生物学差异。
- **后果：** 分类器可能把"四周露出多少背景"当作捷径；S3 的开发、Lacuna-B 支撑的结论（B1u-c0 只有 0.852、S4/S5 的停止规则），都是在这种混杂下得到的。

## 2. 改动：两类都用同一个检测器取框

- **检测器：** 冻结的 Hough 检测器，参数照 E7 检测器附录（PREREG_E7_LACUNA_ADDENDUM_DETECTOR_20261022.md，sha 66a048f4…）：param1 = 30、param2 = 15、缩放使 r0 ≈ 20 px、绿通道、σ = 2、dp = 1、minDist = 20、半径 12–28；r0 取该子站点全部 Parasitized 框 (w + h)/4 的中位数。一个参数都不改。
- **对 Lacuna-B 每张留出图的全部检测，按与标注 Parasitized 框的 IoU 分配类别：**
  - **阳性：** 与某个 Parasitized 框的 IoU ≥ 0.5（与 E7 定义"检测召回"时用的 IoU 阈值相同）；
  - **阴性：** 与所有 Parasitized 框的 IoU 都 < 0.1（与 E7 原来的阴性排除规则相同）；
  - **剔除：** IoU 在 0.1 到 0.5 之间的，计数后剔除；
  - 其余排除规则照 E7：整个框在视野内、距离变换 ≥ 2r、去重半径规则。
- **裁剪：** 两类都取检测圆的外接方框，并与 E7 原阴性用同一外扩（照 e7_crop_v2.py 阴性分支），按原分辨率保存。
- **调参集：** 40 张调参图照旧排除（tuning == 1）。
- **代价：** 阳性数会下降。Lacuna-B 的检测召回是 0.776（E7 记录），阳性约从 4,074 降到 3,100 左右，灵敏度的区间会变宽，照实报告。没被检测器找到的感染细胞计数报告，并分析偏倚：是哪类细胞漏检，比如形状不规则的、和别的细胞粘连的。

## 3. 重建后的验收（事先写定）

1. 用同一个测量脚本 `lacuna_frame_measure.py`（52f1324f…，不改）在重建版上重测：两类 central_frac 中位数差 ≤ 0.05。
2. 两类边长中位数之差 ≤ 10%。
3. 目检：每类 24 张，明显分错（框住两个细胞之间、框中心不在细胞上、截到半个细胞）≤ 3 张，由主会话判读。
4. 阳性数 ≥ 2,000。
- 全部满足，重建版才取代旧 Lacuna-B，作为 P5 的开发站点；不满足只报告，不调检测器参数。由主会话提出下一步改动，交用户。

## 3b. 补充（实验管理审阅后，10-25）

5. **漏检造成的选择偏倚（报告项）：** 检测召回只有 0.776，没被检测到（即没有 IoU ≥ 0.5 的检测框）的 Parasitized 细胞，可能偏向某些类型。报告"被剔除阳性"和"保留阳性"在以下几方面的分布对比：
   - 标注框的面积、边长、宽高比；
   - 中心细胞掩码占比（用同一个测量函数）；
   - 所在视野（每视野的阳性数、视野内细胞密度，后者用检测框数作代理）；
   - 是否与其他标注框相邻（IoU > 0 或中心距 < 2r）。

   两组中位数相差超过 20%（面积、密度），或分布形状明显不同，就在稿件局限中写明重建版阳性的偏向。这一项**只报告，不作为通过或失败的判据**（第 3 节的 4 条验收不变）。

6. **标注完整性与阴性的含义：** Lacuna 的原始标注只给出了 Parasitized、Trophozoite、Gametocyte、WBC、Artifact 等框，**没有给未感染红细胞画框**（E7 预注册第 3 节："阴性（未标注红细胞）"）。数据集是否对每个视野里的每个感染细胞都做了完整标注，主会话没有读过数据集说明的全文，**无法确认**。因此：
   - 重建版的"阴性"如实称为"**未标注为感染的检测细胞**"，不称"未感染"；
   - 继续使用 E7 已有的标签噪声处理：在 η ∈ {0, 0.01, 0.02, 0.05, 0.10} 下报告实际 FPR 的下界 max(0, FPR_obs − η)，覆盖率同时报告 η = 0 和 η = 0.10 两种口径；
   - **查找结果（10-25）：**
     - VM 上已下载的 Thin_Uganda.rar 只含 images/、Labels-YOLO/ 和 Labels-CSV.csv（列 Image_name, xmin, ymin, width, height, Class），没有任何说明文件（fork 只读核查）。
     - Dataverse 元数据（主会话经公开 API 只读获取）：标题"Lacuna Malaria Datasets"，作者 Makerere AI Lab，许可证 CC BY 4.0。描述只有一句："The images have been annotated with bounding boxes showing different objects of interest in each image."，**没有说明谁标注，也没有说明是否把每个感染细胞都标全了**；没有相关发表论文。
     - 记录里附有 Uganda 的数据说明 PDF（datasheet），可能写有这些信息；下载它需要用户批准，尚未下载。
     - 在得到说明之前，稿件写"标注完整性未见说明"。
